# ConnectFlight

Página inicial em React baseada em protótipo do Figma — Programação para WEB II (UNITINS).

Stack: React 18, Vite, React Router, styled-components.

## Rodar
```
npm install
npm run dev
```

## Estrutura
- `src/components`: Layout, Footer, Wave, Hero, PageTitle, PackageCard, CardGrid, ContactForm
- `src/pages`: Home, Destinos, Ofertas, Contato
- `src/data`: dados dos pacotes
